# 🐍 Класична гра «Змійка» на Arduino та NeoPixel (WS2812B)

Проєкт класичної гри **«Змійка» (Snake)**, реалізований на платформі Arduino з використанням адресованої світлодіодної матриці 8x8 (WS2812B) та аналогового джойстика.

---

## 🛠 Компоненти та обладнання

| Компонент | Кількість | Примітка |
| :--- | :---: | :--- |
| **Arduino** (Uno / Nano / Pro Mini) | 1 шт. | Будь-яка сумісна плата |
| **LED-матриця WS2812B** | 1 шт. | 8x8 (64 адресованих світлодіоди) |
| **Аналоговий джойстик** | 1 шт. | Модуль двоосьовий (X/Y) |
| **Дроти DuPont / Макетна плата** | — | Для з'єднання елементів |
| **Джерело живлення** | 5V | USB або зовнішній блок живлення |

---

## 🔌 Схема підключення

### 1. LED-матриця WS2812B
* **DIN (Data In)** $\rightarrow$ Digital Pin **7** на Arduino
* **5V / VCC** $\rightarrow$ 5V на Arduino *(або зовнішнє джерело 5V)*
* **GND** $\rightarrow$ GND на Arduino

### 2. Аналоговий джойстик
* **VRx (Вісь X)** $\rightarrow$ Analog Pin **A3**
* **VRy (Вісь Y)** $\rightarrow$ Analog Pin **A4**
* **VCC** $\rightarrow$ 5V
* **GND** $\rightarrow$ GND

---

## 📦 Необхідні бібліотеки

Для роботи коду потрібна бібліотека для адресованих світлодіодів. Встановіть її через **Library Manager** в Arduino IDE:

* **Adafruit NeoPixel** (автор: *Adafruit*)

---

## 🎮 Ігровий процес та особливості

* **Керування:** Відхиляйте джойстик у відповідну сторону для зміни напрямку руху змійки.
* **Межі поля:** Змійка «проходить крізь стіни» — при виході за край матриці вона з'являється з протилежного боку.
* **Зростання:** При поїданні «яблука» довжина змійки збільшується на 1 сегмент, а нове яблуко спавниться у випадковій точці.
* **Game Over:** Зіткнення з власним хвостом викликає затримку та скидання гри до початкового стану.

🚀 Як запустити проєкт
Клонуйте репозиторій або скопіюйте файл коду у свій скетч Arduino IDE.

Підключіть компоненти згідно зі схемою.

Встановите бібліотеку Adafruit_NeoPixel.

Виберіть правильну плату та COM-порт у меню Tools.

Завантажте скетч на плату.
